## Contexto

O projeto ainda não tem um histórico de versões. Quem baixa o jogo não sabe o
que mudou entre uma entrega e outra.

## Proposta

Criar um `CHANGELOG.md` na raiz, seguindo o formato Keep a Changelog, com a
versão inicial 0.1.0.

## Critérios de aceite

- [ ] Arquivo `CHANGELOG.md` na raiz
- [ ] Seção `[0.1.0]` listando as funcionalidades atuais
- [ ] Link para o changelog no README
